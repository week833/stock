# new path here only when the corresponding program is intentionally adopted.
# Historical revisions belong in Git history, not in additional manifest files.
#
# Active source/tool/test paths are listed in deterministic
# case-insensitive ordinal Windows-path order. Backup, cache,
# virtual-environment, bytecode, pytest-cache, and vendor trees are excluded.
#
# Retired files: programs\...\_retired\ folders hold files moved verbatim out of
# the active tree (never deleted; each folder has a README with the reason).
# They stay registered here at their _retired path because the verifier has no
# skip list for them; a move into _retired updates the entry to the new path.
