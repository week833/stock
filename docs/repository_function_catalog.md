# 外部 GitHub Repository 功能目錄

本目錄以 2026-08-30 本機唯讀快照為準，涵蓋 D:/stock/GitHub 下的 92 個外部
repository：49 個 repos 內 canonical clone 與 43 個 root-level external clone。
Junction 是相容別名，不另列為 repository；固定 root 本身不列入本功能目錄。

## 先看這裡

- 需要台灣行情、交易所資料或台股分析範例：先看 taiwan_market_data。
- 需要全球資料平台：看 global_market_data。
- 需要預測、特徵、模型解釋或超參數研究：看 machine_learning_forecasting。
- 需要策略回測：看 backtesting_engines。
- 需要技術指標、因子、績效或投組風控：看 quant_portfolio_risk。
- 需要 Agent、Skill、Claude Code 或三竹 UI 互動研究：看 ai_agent_tools。
- 需要追查舊相容來源：看 legacy_compat；它們不可當成新 runtime 依賴。

## 使用邊界

所有列出的外部 GitHub repository 都是 optional research。它們不是本專案的正式
runtime 依賴，不可直接成為正式推薦、模型輸入、交易下單或發布依據。表中的用途
欄位，對 37 個 primary 與 2 個 legacy 來源是 scripts/sources/source_manifest_v1.json
的 usage 欄位之繁中標註；AI/Agent 的 10 個用途與根目錄 external 的用途依各
repository 當地 README 的明確說明整理。未明確寫在索引或 README 的功能不猜測。
